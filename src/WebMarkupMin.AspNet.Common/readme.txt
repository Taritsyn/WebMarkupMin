   ===========
   DESCRIPTION
   ===========
   WebMarkupMin.AspNet.Common is auxiliary package, that contains classes and
   interfaces for all ASP.NET extensions.

   This package contains four compressor-adapters for compression of text content:
   `GZipCompressor`, `DeflateCompressor`, `BrotliCompressor` (.NET Core App 3.0 or
   higher) and `ZstdCompressor` (.NET 11 or higher).
